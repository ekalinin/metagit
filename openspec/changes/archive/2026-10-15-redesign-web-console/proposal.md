# Proposal

## Why

Веб-интерфейс metagit сейчас оформлен как типовая админка в палитре GitHub: таблицы в карточках, цветные метки, одна светлая тема. Главный вопрос владельца - "все ли хостинги получили мои ветки и что пошло не так" - не виден с первого взгляда: состояние target'ов теряется среди колонок таблицы. Темной темы нет.

## What Changes

- Новое визуальное направление "диспетчерский пульт". Проект показан как магистраль, target'ы - как ответвления от нее, у каждого ответвления сигнальный огонь: зеленый (синхронизирован), желтый (ожидает), красный (ошибка), погашенный (target выключен).
- Цвет обозначает только состояние. Остальной интерфейс монохромный: графит на светлой эмали в светлой теме, светлые линии на темной панели в темной.
- Светлая и темная темы. По умолчанию тема следует настройке ОС. В шапке переключатель "Системная / Светлая / Темная", выбор сохраняется в браузере.
- Новая типографика: Golos Text для текста, Martian Mono для refs, URL, хэшей, времени и крупных заголовков. Шрифты собираются в бинарник вместе с интерфейсом, интерфейс не обращается к сторонним серверам.
- Новая компоновка: шапка, список проектов со строкой сигнальных огней по target'ам, страница проекта, где адреса для клонирования ведут магистраль к таблице target'ов с линиями доставки.
- Тексты, подписи кнопок и полей, поведение страниц, маршруты и API не меняются. Текстовые метки состояний остаются рядом с огнями.

### Non-goals

- Вкладки, диалоги вместо встроенных форм, кнопки копирования и другие изменения поведения.
- Перевод интерфейса на другие языки.
- Изменения API и серверной части, кроме сборки нового интерфейса в бинарник.
- Лендинг проекта.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `web-console`: добавляется выбор темы оформления и требование загружать все ресурсы интерфейса из самого metagit. В требовании о статусе доставки уточняется, что состояние target'а передается текстом, а не только цветом.

## Impact

- `web/src/style.css`: переписывается целиком (токены светлой и темной тем, типографика, компоновка).
- `web/src/App.tsx`, `web/src/ui.tsx`, `web/src/pages/*.tsx`: точечные изменения разметки для шапки, переключателя темы, сигнальных огней и линий доставки. Имена компонентов, тексты и обработчики сохраняются.
- `web/index.html`: ранняя установка темы до отрисовки React, `color-scheme`.
- `web/package.json`: две новые зависимости со шрифтами под OFL-1.1 (`@fontsource-variable/golos-text`, `@fontsource-variable/martian-mono`).
- Бинарник `metagit` вырастает примерно на 120-200 КБ за счет шрифтов (латиница и кириллица).
- Тесты `web/src`: существующие проходят без изменения запросов по тексту и ролям, добавляются тесты на переключатель темы.
