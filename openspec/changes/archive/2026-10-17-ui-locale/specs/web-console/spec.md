# Spec Delta

## ADDED Requirements

### Requirement: Язык интерфейса
Веб-интерфейс SHALL поддерживать русский и английский языки. Владелец SHALL иметь возможность выбрать на странице настроек один из режимов: "Системный", "Русский" или "English" (в английском интерфейсе "System", "Русский", "English"). Названия "Русский" и "English" MUST показываться на этих языках при любом языке интерфейса. По умолчанию MUST действовать режим "Системный": интерфейс показывается на первом поддерживаемом языке из списка предпочитаемых языков браузера, а если поддерживаемого языка в списке нет - на английском. Выбор MUST сохраняться в браузере и применяться на всех страницах, включая страницу входа, уже при первой отрисовке. Смена режима MUST сразу применяться ко всему интерфейсу без перезагрузки страницы. Атрибут `lang` документа и формат дат и времени MUST соответствовать языку интерфейса. Тексты, которые приходят с сервера (ошибки, сообщения событий, текст ошибки доставки), MUST показываться как есть, без перевода.

#### Scenario: Браузер на русском
- **WHEN** браузер без сохраненного выбора первым предпочитает язык `ru-RU`
- **THEN** интерфейс показан на русском, а атрибут `lang` документа равен `ru`

#### Scenario: Неподдерживаемый язык браузера
- **WHEN** браузер без сохраненного выбора предпочитает только язык `de`
- **THEN** интерфейс показан на английском

#### Scenario: Ручной выбор сохраняется
- **WHEN** владелец выбрал "English" и перезагрузил страницу, а браузер предпочитает язык `ru-RU`
- **THEN** интерфейс показан на английском

#### Scenario: Смена языка без перезагрузки
- **WHEN** владелец в русском интерфейсе выбирает на странице настроек "English"
- **THEN** шапка, заголовки, подписи и кнопки сразу показаны на английском, даты - в английском формате, атрибут `lang` документа равен `en`, страница не перезагружалась

#### Scenario: Язык на странице входа
- **WHEN** владелец выбрал "English" и вышел, а браузер предпочитает язык `ru-RU`
- **THEN** страница входа показана на английском

#### Scenario: Текст ошибки с сервера
- **WHEN** в русском интерфейсе сервер отвечает на запрос ошибкой с текстом `invalid name or password`
- **THEN** интерфейс показывает текст `invalid name or password` без изменений

## MODIFIED Requirements

### Requirement: Статус доставки и журнал событий
Для каждого проекта веб-интерфейс MUST показывать состояние каждого target'а (см. `mirror-replication`): "синхронизирован", "ожидает" или "ошибка" (в английском интерфейсе "synced", "pending", "error") с текстом последней ошибки, а также время последней успешной доставки. Состояние MUST передаваться текстом. Цвет и другие графические обозначения состояния MUST NOT заменять текст, а только дополняют его. Веб-интерфейс MUST показывать журнал событий проекта: ошибки доставки, расхождения на target'ах с именем архивного ref и архивы, созданные при push.

#### Scenario: Расхождение в журнале
- **WHEN** metagit обработал расхождение `main` на target'е `github`
- **THEN** в журнале проекта есть событие с именем target'а, ref и архивного ref

#### Scenario: Ошибка доставки в статусе
- **WHEN** доставка на target `bitbucket` завершилась ошибкой аутентификации
- **THEN** у target'а `bitbucket` состояние "ошибка" с текстом ошибки без учетных данных

#### Scenario: Состояние без цвета
- **WHEN** владелец не различает цвета или смотрит на страницу проекта в любой из тем
- **THEN** состояние каждого target'а читается по текстовой метке "синхронизирован", "ожидает" или "ошибка" (в английском интерфейсе "synced", "pending" или "error")

### Requirement: Выбор темы оформления
Веб-интерфейс SHALL поддерживать светлую и темную темы. Владелец SHALL иметь возможность выбрать один из режимов: "Системная", "Светлая" или "Темная" (в английском интерфейсе "System", "Light", "Dark"). По умолчанию MUST действовать режим "Системная", в котором тема следует настройке ОС. Выбор MUST сохраняться в браузере и применяться на всех страницах, включая страницу входа, уже при первой отрисовке, без кратковременного показа другой темы.

#### Scenario: Первое открытие
- **WHEN** браузер без сохраненного выбора открывает веб-интерфейс, а ОС использует темный режим
- **THEN** интерфейс показан в темной теме

#### Scenario: Ручной выбор сохраняется
- **WHEN** владелец выбрал режим "Светлая" и перезагрузил страницу, а ОС использует темный режим
- **THEN** интерфейс показан в светлой теме

#### Scenario: Системный режим следует за ОС
- **WHEN** выбран режим "Системная" и ОС переключилась с темного режима на светлый
- **THEN** интерфейс переходит в светлую тему без перезагрузки страницы

#### Scenario: Тема на странице входа
- **WHEN** владелец выбрал режим "Темная" и вышел
- **THEN** страница входа показана в темной теме
