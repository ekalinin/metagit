# Proposal

## Why

У metagit нет публичной страницы: описание проекта есть только в README на русском, а репозиторий готовится к открытию для всех. Нужен лендинг на GitHub Pages, который на английском объясняет, что такое metagit, зачем он нужен и как его поставить.

## What Changes

- Новый статический лендинг на английском в каталоге `site/`: одна страница на HTML и CSS, без сборщика и без JavaScript.
- Содержание страницы строится только на фактах из `README.md` и `INSTALL.md`: что такое metagit, зачем он нужен, как работает доставка, пример вывода push, скриншоты интерфейса, быстрый старт, что не входит в эту версию, ссылки на репозиторий и `INSTALL.md`.
- Оформление в направлении "диспетчерский пульт" из веб-интерфейса: те же цвета, шрифты Golos Text и Martian Mono, линии доставки с сигнальными огнями. Светлая и темная тема по настройке ОС, скриншоты в теме страницы.
- Все ресурсы страницы (шрифты, картинки, стили) лежат в `site/`, страница не обращается к сторонним серверам, счетчиков и аналитики нет.
- Новый workflow GitHub Actions публикует `site/` в GitHub Pages при push в `main` с изменениями в `site/` и по ручному запуску. Адрес: `https://ekalinin.github.io/metagit/`.

### Non-goals

- Версии страницы на других языках и переключатель языка.
- Переключатель темы на странице.
- Перевод `README.md`, `INSTALL.md` и веб-интерфейса на английский.
- Собственный домен, блог, документация на сайте, живое демо.
- Релизы и готовые бинарники: быстрый старт описывает сборку из исходников, как `INSTALL.md`.
- Изменения в сервисе metagit и его веб-интерфейсе.

## Capabilities

### New Capabilities

- `project-landing`: публичная страница проекта на GitHub Pages - содержание, оформление и темы, отсутствие сторонних ресурсов, доступность, публикация.

### Modified Capabilities

Нет.

## Impact

- Новый каталог `site/`: `index.html`, `style.css`, шрифты (латиница Golos Text и Martian Mono из пакетов `@fontsource-variable` с текстом лицензии OFL-1.1), выбранные скриншоты из `docs/screenshots/`, иконка сайта.
- Новый `.github/workflows/pages.yml`. Существующий `ci.yml` не меняется.
- `docs/testing.md`: раздел о том, как проверяются сценарии `project-landing`.
- Код сервиса, `web/`, `Makefile` и сборка бинарника не меняются.
- Публикация требует, чтобы владелец включил GitHub Pages в настройках репозитория с источником "GitHub Actions". Пока репозиторий приватный, Pages доступны только на платном тарифе GitHub, а ссылки со страницы на репозиторий ведут на 404 для посетителей.
